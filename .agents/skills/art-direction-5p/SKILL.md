# Art Direction 5p

Use this skill when writing or reviewing `docs/game/3-art-direction.md`.

## Output Contract

Write a Stage 3 art direction document only when visual direction or a finished-quality sample is the current production blocker. Cover the current playable increment, not a full-game art bible.

Use exactly these six sections, in this order:

1. Visual Pillars
2. Color Palette
3. Typography And UI Tone
4. References
5. Style Rules
6. Sample Plan

## Caps

- Absolute cap: 5 pages. This is a maximum, not a target or minimum.
- Keep decisions limited to what the current playable increment needs to look coherent and measurable.
- Prefer short tables and bullets over long art-bible prose.

## Required Shape

- Visual Pillars must connect each visual direction to a macro design Pillar and to the kind of fun validated in Stage 2 learnings. Do not write unsupported taste declarations.
- Color Palette must name primary, secondary, and warning colors plus usage rules.
- Typography And UI Tone must describe font direction and UI copy tone.
- References must list reference games or works with `steal` and `do not steal` notes for each.
- Style Rules must state consistency rules such as resolution, pixel density, silhouettes, outlines, animation density, or equivalent style constraints.
- Sample Plan must define one art sample to make at finished quality in the current increment and its completion criteria. One finished-quality sample is better than broad unfinished coverage.

## Block

Block drafts that contain:

- Full-game art production plans beyond vertical-slice needs.
- Art-direction work that is not needed to unblock the current playable increment. A visual game alone is not a sufficient trigger; keep minimal visual direction in the VS specification when that is enough.
- Engine, framework, toolchain, pipeline, or technology-stack decisions that belong to `tech_decider`.
- Concrete gameplay effects for characters, enemies, items, or abilities.
- Meta sections such as "what this document decides" or "what this document does not decide".
- Visual direction that is not connected to Stage 2 learnings or macro pillars.

## Completion

Complete only when `docs/game/3-art-direction.md` has the six required sections in order, stays within the 5-page cap, every visual pillar is tied to macro/Stage 2 evidence, and the Sample Plan names one finished-quality sample for the current increment with completion criteria. Report the remaining visual risk without adding an artifact-level confirmation gate.
