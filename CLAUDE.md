# Game Design Harness

Follow `AGENTS.md` for game-design harness runtime rules.

## Main-Loop Skill Flows

- Stage 0 interviews are handled directly by the main agent using `.agents/skills/pitch-one-pager/SKILL.md`.
- Stage 2 cycle planning is handled directly by the main agent using `.agents/skills/prototype-hypothesis/SKILL.md`.
- If installed, Stage 2 playtest logging is handled directly by the main agent using `.agents/skills/playtest-log-template/SKILL.md`.
- If installed, post-Stage 3 current-batch planning is handled directly by the main agent using `.claude/skills/production-plan/SKILL.md` after the user confirms the Stage 3 gate.
